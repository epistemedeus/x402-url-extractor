The queue has one caller-owned writer. A stable result is atomically written;
identical reruns read it back, and conflicting output is refused. Tests kill
owned child processes before/after rename and restart using the same queue.
Crash debris is ignored and removed only in the owned test directory. This is
ordinary file recovery, with no append ledger or background job engine.

`buildHandback(queuePath, {prior})` can recheck a caller-held previous handback.
