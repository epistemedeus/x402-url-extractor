The original receiver below is preserved. Current branch CI runs only the
[inert Base composition controls](base/README.md), with no live quote or paid
request. The [canonical-host follow-up](base/CANONICAL-REPRO.md) preserves the
original failed observations and distinguishes quote compatibility from one-shot
retry policy. No paid route is admitted by either fixture.

This finite public acceptance fixture checks `nanoodle` source0.13.0 at
`edd757fe2d5185072a53e43fbfd861c9a5400158`. It reuses the official executor,
not a replacement graph implementation. The owner control uses a synthetic
input,not a customer's requested poem. No key,wallet,signer or payment callback
that can send money is supplied. A callback deliberately stops the run at its
first payment request. No completion URL is called.

The cases receive the actual text-to-LLM input mapping,model,low effort and
400-token cap;explicit keyless operation despite a synthetic environment key;
the refusal of a Base-only offer by the stock Nano parser;and one real unsigned
quote through the stock executor. Returned payment IDs,addresses,links and
Lightning tokens are excluded from the public result. Quote amounts are an
estimate/deposit observation,not final inference cost or whole-job economics.

The standard public Linux runner is finite,read-only and branch-scoped. It
installs no persistent agent,cache or artifact service and changes no default
branch or deployment. Source is MIT-licensed upstream;all fixture content is
synthetic. No paid API call,bid,award,customer delivery or revenue is established.

The potential later consumer is an authorized buyer's supplied graph. A real
assignment,actual runnable payment route and separately bounded authority still
precede its execution. The source test neither authorizes payment nor silently
substitutes a model or executes a buyer's work before selection.
